## Notes for M10-M12

- V100 has no native bf16; torch reports it as supported but emulates it. Use fp16 on V100 or request an A40/A100 for the real fine-tune.
- `--gres=gpu:1` can hand out P100s, which torch 2.8 does not support. Request a type explicitly (`v100`, `a40`, `a100`).
- Node d14-16's V100 threw ECC errors and failed CUDA init on 2026-10-18; exclude it until CARC resets it.
- Adapters and reports are written to `/project2/xiangren_1987/group_40/runs/`, outside the repo.
