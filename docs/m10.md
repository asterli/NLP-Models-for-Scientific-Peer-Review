# M10: prompted claim-extraction baseline

- **Completed:** zero-shot baseline with untuned Qwen2.5-7B-Instruct over all 20 source papers; predictions saved in the shared Claim schema.

## Method

- `scripts/baseline_claims.py`: numbers each paper's sentences (`s001 [section]: text`), asks for a JSON list of CLAIM sentence IDs, greedy decoding. System prompt restates the CLAIM/BACKGROUND rule from `data/claims/claim_labeling_guide.md`.
- Output: `data/claims/predictions/baseline_qwen7b.jsonl` (`claim_id`, `paper_id`, `sentence_id`, `text`). Raw model text per paper is in `/project2/xiangren_1987/group_40/runs/m10_raw_outputs.jsonl`.
- All 20 papers, 27 s on a V100. 59 claims predicted total (1-4 per paper).

## Preliminary scoring (not final)

Scored against one annotator's labels on 4 papers (132 sentences, 33 gold claims). These labels are not yet merged or adjudicated and the papers may land in any split, so this is a sanity check, not the M12 evaluation.

| | value |
|---|---:|
| precision | 1.00 |
| recall | 0.36 |
| F1 | 0.53 |

Every predicted claim was correct (12/12). Misses were mostly result sentences in abstracts and stated aims in introductions; the model tends to return only 2-4 sentences per paper.
