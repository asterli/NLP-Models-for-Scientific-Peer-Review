# M11 / F05: fine-tuned claim extractor

- **Status:** first full run complete; settings selected on dev. Second seed pending (see below). Test untouched.
- **Model:** Qwen2.5-7B-Instruct + LoRA (r=16, alpha=32, dropout 0.05, targets q/k/v/o_proj), bf16, gradient checkpointing.
- **Task format:** identical to the M10 v2 prompt. Input = system prompt + numbered sentences of one paper; target = one `sXXX: CLAIM|BACKGROUND` line per sentence. Loss on the assistant turn only.
- **Code:** `scripts/train_claims.py` (train + per-epoch dev selection), `scripts/predict_claims.py` (reload adapter, label a split), `src/claims/prompting.py` (shared prompt/data/parse), `tests/test_claims_prompting.py` (no-GPU tests). Batch runner `scripts/slurm/m11_train.sbatch`.
- **Data:** M08 train split (14 papers, 445 sentences, 113 CLAIM) for training; dev split (3 papers, 80 sentences, 18 CLAIM) for epoch selection only.

## Run `r16_lr2e-4_s544`

Settings: lr 2e-4 (linear decay), AdamW, batch = 1 paper, grad-accum 2, 8 epochs, seed 544, grad-clip 1.0. A40, 6.5 min total, peak 21.7 GB.

| epoch | train loss | dev P | dev R | dev F1 | predicted claims |
|---:|---:|---:|---:|---:|---:|
| 1 | 0.038 | 0.87 | 0.72 | 0.79 | 15 |
| 2 | 0.012 | 0.71 | 0.94 | 0.81 | 24 |
| **3** | 0.005 | **0.81** | **0.94** | **0.87** | 21 |
| 4 | 0.002 | 0.81 | 0.94 | 0.87 | 21 |
| 5–8 | <0.001 | 0.75 | 0.83 | 0.79 | 20 |

- Best epoch 3 (first to reach the max), saved as `best/`. Epochs 5+ overfit: train loss → 0, dev F1 falls.
- Fresh-process reload of `best/` reproduces the epoch-3 dev score exactly (`results/m11_dev_r16_lr2e-4_s544.json`: P 0.81 / R 0.94 / F1 0.87, 17/18 claims found, 4 FP).
- Of the 4 false positives, `s001` and `s023` are the two suspected gold-label errors noted in `docs/m10.md`.

## Reproduce

    sbatch scripts/slurm/m11_train.sbatch                                   # defaults = r16_lr2e-4_s544
    RUN=r16_lr2e-4_s2026 EXTRA="--seed 2026" sbatch scripts/slurm/m11_train.sbatch
    RUN=r8_lr1e-4_s544 EXTRA="--lora-r 8 --lora-alpha 16 --lr 1e-4" sbatch scripts/slurm/m11_train.sbatch

Standalone inference from a saved adapter (any split; test only in M12):

    python scripts/predict_claims.py --adapter /project2/xiangren_1987/group_40/runs/m11/r16_lr2e-4_s544/best \
        --split dev --out data/claims/predictions/finetuned_dev.jsonl

Needs a bf16 GPU (A40/L40S/A100). On a V100 add `--load-4bit` to both train and predict.
