# M08 — Claim Dataset Splits

The reviewed M07 claim dataset was split by source paper.

- Train: 14 papers (~70%)
- Dev: 3 papers (~15%)
- Test: 3 papers (~15%)

All sentences from the same paper remain in the same split.

Duplicate papers and alternate versions of the same paper were checked before freezing the splits.

- The two At Home/Chez Soi papers (PMC12314730, PMC8382791) report the same trial, so both are in train. To keep 3 dev papers, doi:10.1111/1475-6773.14411 moved from train to dev.
