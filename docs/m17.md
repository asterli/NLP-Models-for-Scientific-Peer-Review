# M17: pilot fine-tuning

- **Completed:** trained on labeled claim–passage pairs, saved checkpoints, and verified identical prediction scores after fresh offline reload.

## Exploratory evaluation

- **Pilot:** 30 comparisons from four source papers; 19 distinct, 9 overlapping, 2 insufficient evidence. Human explanations were excluded from model inputs.
- **Evaluation:** held out one source paper at a time, with duplicate exclusions; 19–24 training examples per run. Repeated with two seeds.
- **Best trained candidate tested:** Qwen2.5-7B-Instruct (4-bit) with LoRA. Both seeds scored 20/30; mean macro-F1 was 0.457. Always predicting distinct scored 19/30 and 0.259; fine-tuned DistilBERT scored 17/30 and 0.246.
- **Limitations:** 11/30 Qwen predictions changed between seeds; neither run correctly classified either insufficient-evidence example. This is preliminary feasibility evidence, not final classifier validation.
- **Next:** broader labeled data, especially insufficient evidence; official paper-level splits and an untouched final test. Treat this pilot as development data.

## Included code

`scripts/train_novelty.py` and `src/novelty.py` support CPU encoder training and inference. The default three steps verify execution, not accuracy. The Qwen/LoRA evaluation implementation is not included.

Run with a local pretrained encoder such as `distilbert/distilbert-base-uncased`:

```bash
pip install -r requirements-novelty.txt
python scripts/train_novelty.py --data /path/to/pilot.jsonl --base-model /path/to/local/encoder --output /path/to/new/checkpoint
```

Input JSONL fields: `comparison_id`, `claim`, `prior_work`, `label`. Labels: `overlapping`, `distinct`, `insufficient_evidence`. Load the saved directory with `NoveltyClassifier` in `src/novelty.py`; call `predict(claim, prior_work)`. It returns a label and an uncalibrated score; explanations and pipeline metadata are not generated.
